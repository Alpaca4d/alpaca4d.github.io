# 🎯 Optimisation

Letting Alpaca4d find the design: the sections of a steel frame, or the shape of a structure.

- [Size steel beams automatically](size-beams.md): the lightest sections that pass EN 1993-1-1, with the Section Optimiser.
- [Find a structure with topology optimisation](topology.md): keep only the material the loads need, from a block of bricks or tetrahedra.

Every input of the components these use is on their reference pages: [Section Optimiser](../../basics/optimisation/section-optimiser.md), [Design Group](../../basics/optimisation/design-group.md), [Topology Optimisation](../../basics/optimisation/topology-optimisation.md). For design studies and searches over a definition's sliders, see [Optimisation](../../basics/optimisation/README.md).
