# Modal Analysis Report

{% hint style="info" %}
**Retired.** The modal report is now part of
[Natural Vibration](../analysis/natural-vibration.md): its nine sections are outputs in the
component's [Modal Report](../analysis/natural-vibration.md#modal-report) menu, under the same
names. The report is written by that analysis and read by nothing else, so a second component
only ever sat wired to the first.

Definitions that already use `Modal Analysis Report (Alpaca4d)` still open and work; the
component is hidden from the ribbon.
{% endhint %}
