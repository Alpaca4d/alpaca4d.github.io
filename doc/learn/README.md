# 🏝️ Learn

The lessons follow the island of the [Playground](https://alpaca4d.github.io/playground.html): ten
areas, each with a structure to build and one idea of structural engineering to take away. Each
lesson starts with a picture of what you will build and the Grasshopper file, start and finished,
then a few steps, a check against a hand calculation, and something to try.

{% hint style="info" %}
The lessons are being written. Until a lesson is out, its page says what it will cover and links
to the pages that cover the same ground.
{% endhint %}
