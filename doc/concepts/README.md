# 💡 Concepts

These pages explain rather than instruct: why an Alpaca4d definition is put together the way it
is, what the axes, signs and units mean, and how to choose between elements and analyses. For the
steps, see the [how-to guides](../how-to/README.md); for every input, each component's own page
in the reference.

- [How a model is built](how-a-model-is-built.md): from material to results, and what each stage
  hands to the next.
- [Axes and signs](axes-and-signs.md): global and local axes, and which way the forces point.
- [Units](units.md): what Alpaca4d works in, and what it shows.
- [Which element](which-element.md): beams, trusses, shells, bricks and tetrahedra.
- [Which analysis](which-analysis.md): static, modal, buckling, time history, moment-curvature.
- [Alpaca4d and OpenSees](alpaca4d-and-opensees.md): what happens when an analysis runs.
- [Benchmarks](../benchmark/intro.md): Alpaca4d against beam, shell and brick theory.
