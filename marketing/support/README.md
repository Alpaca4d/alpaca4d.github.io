## The numbers, if someone asks

- **The types:** Rigid (the default), Elastic and Compression Only.
- **Elastic:** a spring along or about each axis, in kN/m and kNm/rad.
- **Compression Only:** holds along the plane's Z while the node pushes into it; a Stiffness in
  kN/m, rigid when empty, and a Gap in m; it lets go only in a non-linear analysis.
- **Older definitions:** the old Support is marked OLD and still works; Upgrade Components swaps it
  for this one, with its wires and values.
