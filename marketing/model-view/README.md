# Model View: LinkedIn post

Model View, the one component that now draws an Alpaca4d model and any of its results. This folder
holds a slab drawn by its Von Mises stress, with its reactions and a legend for each
(`several-results.png`), the Beam forces row with My and Mz ticked (`beam-forces-row.png`), and the
component itself, folded (`model-view.png`) and with every menu open (`model-view-open.png`). The
loads have a post of their own, in `loads/`.

## What to attach

- **The post:** `several-results.png`. There is no video of it.
- **A carousel instead:** `several-results.png`, then `model-view-open.png`.
- **Alt text:** A slab coloured by its Von Mises stress, with arrows at its supports coloured by the
  reaction each carries, and a legend for the stress and one for the reactions beside it.

## The numbers, if someone asks

- **The results it draws:** Displacement, Beam forces, Beam stresses, Shell forces, Shell stresses,
  Brick stresses and Reactions, any number of them at once.
- **The beam force diagrams:** N, Vy, Vz, T, My and Mz, a checkbox each, a diagram each.
- **The units:** picked per result: mm, cm or m for a displacement; N, kN or MN for a force;
  kPa, MPa or kN/cm² for a stress.
- **What it replaces:** the old Model View, which drew the model only, and View Results_WIP. Both
  are hidden; Solution ▸ Upgrade Components swaps them for the new one.
- **The license:** Model View is one of the viewers a license unlocks.
