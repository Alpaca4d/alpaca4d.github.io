## The numbers, if someone asks

- **The springs:** Kx, Ky, Kz in kN/m, Krx, Kry, Krz in kNm/rad; left empty, the node is free that
  way.
- **Compression Only:** a Stiffness in kN/m, rigid when left empty, and a Gap in m before it takes
  hold; analyse it with Newton, in several steps.
- **The symbols:** seven presets get their own; any other support, springs included, a text tag.
